## An indie game caught in Steam’s backed-up review queue finally has a release date.
On November 3rd, I wrote about Food Devils missing its launch date planned for that day while awaiting Valve’s approval — even though developer Studio Daimon submitted its build on October 12th. (Valve acknowledged it is dealing with a “significant increase” in game submissions.) But today, Studio Daimon said Food Devils is now coming out in early access on November 24th.
