## Yakuza creator’s game studio is the latest to shut down.
Nagoshi Studio will never get to release its first game Gang of Dragon, because China’s NetEase stopped funding the studio this summer and it couldn’t find the investment to go indie. We’ve lost a lot of game studios this year, not to mention around 11,000 game developer jobs, but a few studios have managed to go indie.
